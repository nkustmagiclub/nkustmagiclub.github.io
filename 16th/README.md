# 十六週年《阿本洛特》活動頁草稿

獨立路徑：`/16th/`。沿用現有純 HTML / CSS / JavaScript，不需要安裝套件或建置。依使用者要求先放上可直接開啟的網址；首頁、選單、活動列表與 sitemap 不新增入口。

這是未列在導覽中的公開預覽，不是存取限制；知道網址的人仍可開啟。`noindex, nofollow` 是給搜尋引擎的指示，不能當作密碼保護。

## 編輯方式
