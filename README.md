# 高科大魔術社長期入口網站

> **入口頁只改 `EDIT_CONTENT.md`；認識我們改 `ABOUT.md`；活動內頁改對應的 Markdown 檔；換圖片放 `images/`；想改顏色才碰 `EDIT_THEME.css`；其他不要動。**

1. 改入口頁文字／連結：編輯 `EDIT_CONTENT.md`，照檔案最上方範例。
2. 改認識我們：編輯 `ABOUT.md`。
3. 改社團嘉年華：編輯 `CLUB_FAIR.md`。
4. 改街魔行動：編輯 `STREET_MAGIC.md`。
5. 換圖片：放入 `images/`。
6. 改顏色：只改 `EDIT_THEME.css` 冒號後面的值。
7. 改社課時間、教室與停課安排：編輯 `CLASS_SCHEDULE.md`。入口頁只放連結，完整資訊顯示於 `classes.html`。

8. 改指導老師與幹部：編輯 `TEAM.md`，完整介紹顯示於 `team.html`，入口連結放在 `ABOUT.md`。人物照片放在 `images/`；老師的原始師資 PDF 含個人資料，僅使用獨立取出的照片，不要上傳原檔。

## 近期與過往活動

所有活動連結都保留在 `EDIT_CONTENT.md` 的「近期活動」區塊。每筆後面填上結束日期，例如：

```markdown
- [09/22（二）《社團嘉年華》活動資訊](club-fair.html) <!-- until:2026-09-22 -->
```

入口頁只顯示尚未到期的活動，並提供「更多活動」入口。`activities.html` 會顯示近期與過往活動，過往活動依結束日期由新到舊排序；原活動頁、照片與連結都保留。

日期以台灣時區為準，活動當天仍顯示在入口頁，隔天歸檔；跨年也使用完整年份判斷。未填或格式錯誤的日期會繼續顯示，避免活動被誤藏。頁面重新開啟、跨日後切回分頁或每分鐘檢查時，都會更新分類，不需要手動搬動內容。

本次新增頁面與自動歸檔功能已同步更新 `app.js`、`style.css` 與各頁面的版本號；一般文字更新仍照上方對應的 Markdown 檔修改。

內容送出後，GitHub Pages 會自動更新；通常等待幾分鐘再重新整理即可。

## 英文版

英文入口為 `/en/`，認識我們、社課時間及指導老師與幹部分別在 `/en/about.html`、`/en/classes.html`、`/en/team.html`。這四頁頂端可以切換至對應的中英文頁面，純網址 `/` 維持中文入口頁，不依瀏覽器語言自動轉址。

英文文字放在 `en/EDIT_CONTENT.md`、`en/ABOUT.md`、`en/CLASS_SCHEDULE.md`、`en/TEAM.md`，格式和中文 Markdown 相同。更新社團介紹、社課或幹部資料時，請同步更新對應英文檔；圖片、樣式與顯示程式共用原檔。

活動頁維持中文。中英文入口的活動連結都由根目錄的 `EDIT_CONTENT.md` 讀取，到期日與歸檔共用同一套規則，無須在英文檔重複維護。請保留英文入口的 `Upcoming Events` 區塊標題，並將活動連結加在中文原檔的「近期活動」區塊。

## 焦點新聞

入口頁的「焦點新聞」連結在 `EDIT_CONTENT.md` 維護，英文入口在 `en/EDIT_CONTENT.md`。阿本洛特的媒體報導與轉載連結統一放在 `ABENDROT_NEWS.md`，顯示於 `abendrot-news.html`；依報導來源分組，每筆連結標示刊登平台。新聞不使用活動到期日，不會隨活動結束而自動歸檔。
